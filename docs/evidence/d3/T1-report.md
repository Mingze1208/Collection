# T1 泪滴 · 验收报告（2026-11-09）

> 规格：`docs/design/d3-tasks.md` §T1
> 结论：**5 条验收全部通过**；3 次逃脱 3/3 成功、0 失败；未做 T2。

## 实现要点

- `DropletThrower`（挂在玩家身上）：鼠标左键 → `ScreenToWorldPoint` 求光标世界坐标 → 方向 = 光标 − 玩家。
- 落点在投掷瞬间用**墙体 AABB 射线**一次算定（与涟漪同一套墙），射程 6 m 封顶；投射物只是视觉，飞行时间 = 距离 ÷ 16 m/s。
- **投掷本身不发声**：投掷时不调用 `Emit`；落地时才 `Emit(落点, RippleSource.Footstep)`，复用落脚档（48 点 / 3 m/s / 1.2 s）。
- 冷却 2 s；冷却中或上一颗未落地时点击一律无效并计数（`BlockedCount`）。
- 参数全在 `SO_Ripple_V2` 的「泪滴（投掷）」节：速度 / 射程 / 冷却 / 视觉半径。

## 未能自动化的部分（如实说明）

`runtime simulate_pointer` 能返回成功，但**事件没有进入 Input System**（与 `simulate_key` 同一类问题），所以鼠标"点击→投掷"这一跳没有自动化证据。

替代取证：验收 1/2/4 都走 `ThrowAt(世界坐标)`，它与鼠标路径共用同一段投掷逻辑（只跳过"读鼠标 + 屏幕转世界"两步）。屏幕转世界用的是标准 `Camera.ScreenToWorldPoint`，**需要你在实际游玩时确认手感**。
