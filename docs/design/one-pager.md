# 《（ （(涟漪)） ）》One-Pager v1

> 填写规则：每一节只写一句到三句；填不出来的写【待定】，不要写形容词凑数。
> 冻结时把 v0 改成 v1 并写日期，之后每次改动升版本。

## 1. 一句话

一个爱唱歌的女孩，用声音在黑暗的心灵空间里看清过去，躲开由不愉快记忆化成的敌人，与过去和解。

## 2. 核心循环（30 秒一次）

发声 → 读出空间 → 探索未知，决策移动 （→ 躲避敌人） → 获得信息，推进叙事 → 回到发声

- “躲避敌人”部分会让玩家感到怕
- “获得信息，推进叙事”部分会让玩家感到共情

## 3. 玩家动词（≤4）

- 走（被动发声，声音强度中等）
- 唱歌（发出“啊”的声音，主动发声，声音强度大）
- 投掷泪滴（用于在本体之外造出声音）
- 屏息轻轻走（被动发声，声音强度小。有时间限制，时间到而没有停止屏息会发出一个较大声响）

## 4. 独特卖点

用玩法讲故事。

## 5. 叙事骨架（5 拍）

1. 钩子（0–2 分钟）：主角开篇就发现自己身处一片漆黑之中，开始介绍背景：主角喜欢唱歌，父母支持，她上了艺术学校。紧接着一个“但”字吊起胃口。
2. 规则建立：在“钩子”部分的叙述背景的同时，玩家做出操作。图案或字幕指导主角迈出一步，或发出歌声，产生“涟漪”，让周围通过反射而被“看见”。反射效果不同的地方，是“镜子”（门），即关卡终点。
3. 第一次反转：第一章里面是过去的喜悦，而后第二章是过去的悲哀，这悲哀源于主角的歌声渐渐不再纯粹，不是为了自己而唱歌。玩家获得“投掷泪滴”能力，悲哀的“泪水”是可以发射的能够激起“涟漪”的东西。
4. 代价：关卡出现敌人，被敌人追上会Game Over。叙事上这些敌人是主角悲哀的原因。
5. 第二次反转：第三章藏着过去的恐惧，恐惧来源于主角在一系列生活经历之后发觉到自己唱歌的“无意义”。玩家获得屏息轻声走的能力。
6. 代价：敌人变多，出现代表“虚无”的陷阱。叙事上主角会面对精神的崩溃。
7. 结局：（故事线唯一，结局唯一）终章是一个颇有存在主义色彩的结局，主角理解了自己唱歌本身就有意义，在感受自然中结束游戏。

### 叙事结构
- **线性三章**：3 个场景，每章引入一个声学变体。

## 6. 游戏机制细节

- 声音暴露位置，同时照亮空间：同一个动作既给信息又给风险。
- 敌人只靠听，行为可预测：玩家能复盘“我为什么被发现”。
- 静默是资源，不是停顿：不动也在做决策。

- 一句话描述玩家看到的画面：声音的形象是一个以声源处为原点，向多个方向辐射出去的带有逐渐变淡的尾迹的点。碰到墙会反弹且保持与入射时声音强度不变；正常行走声音的运动速度暂定为1m/s，存活时间暂定为2s；尾迹会随着时间慢慢变淡直至消失。
- 敌人行为规则：在接触到声音代表的点之后，会向着这个点所代表的声源点走，并最终停在这个声源点，直到下一次接收到声音。
- 失败后规则：跳出窗口显示“GameOver”，让玩家选择重试（在当前房间入口复活）或返回主菜单。
- “投掷泪滴”规则：泪滴资源无限，但有冷却时间，暂定为2s。

## 10. 成功判据（可观察）

3 个陌生人，在无人提示下 5 分钟内理解“发声=看见”，且至少 1 人说出“我不敢动”或“我感受到了紧张”或“我很想逃”。
