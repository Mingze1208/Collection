# D2 结论（系统落地 + 第一章）

> 输入：`d2-plan.md`、`docs/evidence/d2/`（45 份证据）
> 状态：**D2 计划六项任务全部完成**；任务 5 的试玩由本人完成，反馈的 2 个问题已修复并复验。
> 规模：3 个场景（`SC_Spike` / `SC_Corridor` / `SC_Level01`）、6 个 SO、19 个运行时脚本、约 3600 行代码。

## 结论（10 行）

1. **涟漪 v2 落地**：3 m/s × 1.2 s（≈3.6 m）。在 10.67 × 6 m 视野里几何覆盖 **62.4%**（目标 50–60%，略高），但点只扫过 **25.2%**——24 条射线是"辐条"，中间是黑的。
2. **两档涟漪成立且可独立调**：唱歌 24×8=192 点/次、落脚 12×4=48 点/次，各自有速度/存活/颜色/冷却；唱歌冷却 0.5 s。
3. **屏息静步成立**：3 m 直廊里 7 步静步从驻留敌人侧旁通过，同屏 0 点、敌人 Seek 次数不变；在敌人 2.4 m 内耗尽则发出 192 点大声响并被抓。
4. **接近脉冲成立**：6 m 内出现、6 m 外消失；5 m/0.17 强度/1.17 Hz → 0.9 m/0.85 强度/2.67 Hz；预计被抓前 **0.30 s** 闪红一次；Idle 状态不显示。
5. **第一章可通**：124 m 通路 + 25 面自动生成墙 + 5 根柱子 + 3 个检查点 + 1 个敌人 + 终点门；连续走完 **54.1 s / 154 步**。
6. **失败循环与检查点**：接触即判死（阈值 = 双方半径和 + 0.02）；重试回当前检查点；检查点顺序覆盖、死亡不重置。
7. **叙事与文本**：首段字幕 84 字（≤150），1 s 延迟 + 3 s/行、Enter/Esc 跳过；世界空间富文本支持逐字 + 颜色 + `<wave>` 波浪，逐字 12 字/s。
8. **计划外还做了**：相机 Y 跟随（死区 0.6 / 夹取 ±1.5）、门与检查点改 Box Trigger、多检查点、两档涟漪重构、调试入口收口。
9. **与计划不符两处**：第一章时长 54.1 s ≠ 3–4 分钟（已知，留待内容补齐）；任务 3 的"录屏 10 s"改为逐帧 + 读数（已确认）。
10. **交付阻塞仍在**：`SC_Level01` 不在 Build Settings（现在打包含的是 SampleScene），且从未做过构建验证。

## 踩过的坑（都只有真跑一遍才会暴露）

| 现象 | 原因 | 修法 |
|---|---|---|
| 敌人 2 秒内 `seeks=33` | Camp 状态每帧都重新 BeginSeek | 两状态共用"同目标不重置"判断 |
| 瞬移发出一串落脚声 | 位移被当成走路 | 单帧位移 > 2×步长视为瞬移 |
| 叙事与世界文本整块不出现 | 构建期 ScriptableObject 引用被 AssetDatabase 重载成"假 null" | 用前按路径重新 Load |
| 复活点/残影颜色/文本内容运行时是空 | 构建期赋值的字段没有 `[SerializeField]` | 统一序列化 + 落地值兜底 |
| 玩家卡在 x=27.6 一动不动 | 墙体生成时把每段两端各延长 0.5 m，正好堵住通道口 | 不延长，缺口留在可走区之外 |
| 沿中线走一直蹭墙 | 0.5 m 网格量化把墙面推进走廊 0.25 m | 折线段让开一格，中线净空 ≥0.45 m |
| 连点空格尾迹忽隐忽现 | 无冷却，多 burst 撞 512 上限被裁剪 | 唱歌冷却 0.5 s |
| 试玩找不到"唱歌/落脚"参数 | 只有全局字段 + 两个散落的脚步字段 | 重构成 Voice / Footstep 两档 |
