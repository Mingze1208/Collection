## 3. 难点

1. **中文字体**（最大）：TMP 默认字体无 CJK；需导入 Noto Sans SC 并做 Dynamic 图集字体资产。
2. **波浪 × 富文本坐标耦合**：改顶点要按 `characterInfo[i].vertexIndex` 的 4 个顶点；富文本标签不产生 characterInfo，**可见字序 ≠ 原始字符串下标**，区间映射错位会出现"字在抖、位置错"。
3. **自定义标签**：TMP 只支持内置标签，`<wave>` 需自行解析并剥离，再记录可见字区间。
4. **世界空间渲染 + URP 2D 排序**：World Space Canvas + TMP，需与 Sprite 的 sorting 协调。
5. **与现有 IMGUI 叙事并存/迁移**（`NarrativeIntro` 目前是底部字幕）。

## 4. 决策点（推荐值）
